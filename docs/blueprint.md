# **App Name**: Koop

## Core Features:

- Buyer Menu: Display seller-specific menus (beer, spirits, soft drinks, snacks) with +/- controls for ordering.
- Order Summary: Provide a summary of the current order, including items, quantities, and estimated cost.
- Order Tracking: Show an order status bar (e.g., 'Order Placed', 'Preparing', 'Out for Delivery', 'Delivered').
- Dynamic Map (Buyer): Display a satellite image map with GPS locations of buyer and assigned beverage cart seller after order placement.
- Driver Order Data: Login-protected beverage cart driver page with order details and delivery map showing all buyers.
- Dynamic Map (Seller): Display a satellite image map with GPS locations of all buyers after they order from the specific seller. Use a tool that prioritizes deliveries based on an estimated shortest path. The driver's device will sound a notification alert when the tool suggests a different delivery to follow from the originally selected one.
- Seller Menu Admin: Admin page to create, modify, and manage menus for each seller.
- Seller Account Admin: Admin page to create, modify seller data, and manage seller accounts.

## Style Guidelines:

- Primary color: Muted gold (#B3995D), suggestive of sunshine on the course.
- Background color: Light beige (#F2E9D5), a desaturated version of the primary, to suggest the sand in a sand trap, and offer contrast to other on-screen elements in this light color scheme.
- Accent color: Deep green (#336633) for buttons and active states, echoing the color of the green and fairway.
- Headline font: 'Playfair' serif, for a refined, upscale feel on marketing pages and headings; body: 'PT Sans' sans-serif.
- Use simple, clean icons representing food and beverage categories.
- Emphasize clear, intuitive layouts optimized for mobile use, with prominent CTAs.
- Subtle transitions and animations to enhance user experience and provide feedback.
